* How to use this model *

First thing you have to do is go into your sierra/halflife/cstrike directory, and if they're not there already, create the following folders: "models", and inside that, create another one called "player". Inside "player", create one folder for each model you want to replace. The name of each folder must be exactly the name of the model you want to replace, and for counterstrike (as of beta 5.2) these are: "urban" (navy seal), "gsg9" (german gsg9), "sas" (british SAS), "terror" (camo terrorist) and "arab" (arab terrorist). Inside each folder you place the model you wish to use and name it the same as the folder plus the.mdl suffix. Also, you only need to create these folders for the models you want to replace.
